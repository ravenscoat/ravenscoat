## Featured open-source project

### [Persistent Synthetic User Lab](https://github.com/ravenscoat/Persistent-Agentic-Synthetic-User-Lab)

> Persistent AI users that operate real browsers, remember earlier sessions, and verify application bugs with evidence.

The platform converts plain-English customer journeys into bounded browser tests. Isolated personas navigate applications through Playwright, retain scoped memory, recover from checkpoints, and test multi-session workflows. Model suspicions are separated from deterministic verification, producing replayable reports with expected-versus-observed evidence.

**Architecture:** `Agent Runtime` · `Playwright` · `PostgreSQL` · `Qdrant` · `FastAPI` · `Langfuse` · `Ollama/Qwen`

**Engineering highlights:**

- Persistent persona memory with PostgreSQL as the source of truth and Qdrant as the semantic index
- Isolated browser sessions and private memory scopes for multi-user workflows
- Structured tool calling, stale-action protection, budgets, retries, and checkpoint recovery
- Deterministic invariant checks and replay instead of trusting an LLM-generated verdict
- Local-model execution with optional hosted-model fallback and safe observability

## How I design agentic systems

```text
User goal
   ↓
Planner / Router
   ↓
Context + Scoped Memory
   ↓
Structured Model Decision
   ↓
Validated Tool Execution
   ↓
Checkpoint + Observation
   ↓
Independent Evaluation / Human Approval
```

I prefer a hybrid approach: **the model handles flexible reasoning; deterministic software controls permissions, state transitions, validation, and final verification.**
